# Supplemental program metadata

The application bundles 22 Trame-authored supplemental program records in `GymTracker/Resources/Programs/liftosaur_programs_all.json`. The filename is retained for compatibility with the bundled catalog decoder; the records themselves no longer contain Liftosaur-sourced or mixed-source entries.

The separate authored program library remains in the app. The previous scraped program exports and scraper are no longer distributed. On-device records created by earlier releases are not deleted by this change.
