# Supplemental exercise metadata

The application bundles 21 Trame-authored supplemental exercise records in `GymTracker/Resources/Exercises/liftosaur_exercises_all.json`. The filename is retained for compatibility with the bundled catalog decoder; the records themselves no longer contain Liftosaur-sourced or mixed-source entries.

The independent system exercise seeds remain part of the app. The prior scraped exercise exports, classification report, and scraper are no longer distributed. On-device records created by earlier releases are not deleted by this change.
