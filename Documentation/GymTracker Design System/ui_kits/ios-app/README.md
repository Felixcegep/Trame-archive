# iOS app UI kit

Interactive recreation of GymTracker's four canonical surfaces, grounded in the SwiftUI source (HomeView, ActiveWorkoutView + ExerciseEntryCard/SetRowView, FolderView/LibraryComponents, HistoryView) and the repo's Screenshots/.

- index.html — click-through shell: tab bar, Home \u2192 Start workout \u2192 Active Workout (log sets, rest timer counts down) \u2192 Review returns home with history.
- Screens: HomeScreen, ActiveWorkoutScreen, LibraryScreen, HistoryScreen (+ chrome.jsx status bar/circle buttons).
- Omitted (exists in the app, not recreated here): Settings, Plans/calendar, plate calculator, save/review flow, exercise picker. See assets/screenshots and the repo for those.
