# Trame

**Project status:** Finished and no longer actively maintained. This repository is kept as an archive.

Trame is an iOS training app. Its mobility and yoga catalogue combines app-authored material with data collected from third-party sources.

## Dataset sources and credits

Some catalogue data was collected from public websites and APIs, then transformed or combined with Trame's own seed data:

- [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) by yuhonas — exercise and stretching data, published under the [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md).

Previously bundled Liftosaur, RepDB, and Yoga API exports have been removed from the current catalogues. Some older resource and metadata names remain for compatibility. Data is attributed to its original sources. Attribution alone does not establish permission to scrape or redistribute all content; review the upstream terms and applicable rights for each dataset and image before reuse or publication. See the [mobility dataset notes](Documentation/Resources/Mobility_and_Yoga/README.md).
