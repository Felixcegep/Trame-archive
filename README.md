# Trame

Trame is an iOS training app. Its exercise, program, mobility, and yoga catalogues combine app-authored material with data collected from third-party sources.

## Dataset sources and credits

Some catalogue data was collected from public websites and APIs, then transformed or combined with Trame's own seed data:

- [Liftosaur](https://www.liftosaur.com/) — exercise and program data. Its [source repository](https://github.com/astashov/liftosaur) publishes an [AGPL-3.0 license](https://github.com/astashov/liftosaur/blob/master/LICENSE); the applicable terms for the particular extracted content must be checked separately.
- [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) by yuhonas — exercise and stretching data, published under the [Unlicense](https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md).
- [Yoga API](https://github.com/alexcumplido/yoga-api) by Alexandre C. — yoga pose data and image links. The API code is MIT-licensed; the upstream README specifies separate terms and credits for its images, including Flaticon assets by [monkik](https://www.flaticon.com/free-icons/easy) and [dDara](https://www.flaticon.com/free-icons/yoga).

Data is attributed to its original sources. Attribution alone does not establish permission to scrape or redistribute all content; review the upstream terms and applicable rights for each dataset and image before reuse or publication. See the [mobility dataset notes](Documentation/Resources/Mobility_and_Yoga/README.md).
